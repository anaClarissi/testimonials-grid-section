## 🧠 Sobre o projeto

Este projeto consiste em uma seção de depoimentos desenvolvida como parte de um desafio do **Frontend Mentor**.

O objetivo foi construir um layout moderno utilizando:

* 🎯 CSS Grid
* 📱 Responsividade
* 🎨 Hierarquia visual
* 🧩 Organização de componentes

O design apresenta múltiplos cards organizados em grid, contendo depoimentos de alunos fictícios sobre experiências em um bootcamp.

## 🧩 Como funciona

O layout principal utiliza:

```css
grid-template-areas:
"box-01 box-01 box-02 box-05"
"box-03 box-04 box-04 box-05";
```

Cada card possui:

* avatar
* nome
* status do aluno
* comentário principal
* descrição detalhada

A responsividade foi implementada utilizando **media queries**, adaptando o grid para telas menores.
